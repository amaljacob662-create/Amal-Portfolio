The Alchemist — Book website

  • HTML, CSS, JS, Responsive Design
  • School assignment
  • 2025

Project info

The brief: you've just written your first book — a future bestseller — and need a website to sell it. I built a site for “The Alchemist” from a given mockup, writing all HTML and CSS myself.

My role
Designer & developer
Context
Individual assignment, Medieinstitutet
Year
2025
Tools
HTML, CSS, JS, GitHub Pages
Visit the live site ↗

01 — Overview

A sales website for a first book, built from a given mockup with hand-written HTML, CSS and JavaScript.

02 — The problem

Turn a static mockup into a fast, responsive site that works from mobile to desktop without any frameworks.

03 — Research and insights

  • Studied the mockup's hierarchy: hero, about, chapters, buy form
  • Mobile visitors needed to reach 'Buy now' without long scrolling

04 — Design process

  • Mobile first with three breakpoints
  • Grid and Flexbox, relative units
  • CSS variables for fonts and colours
  • About book & author share markup, mirrored with CSS only

05 — Final solution

Warm sand and gold tones inspired by the desert journey in the story, two consistent typefaces, validated with W3C and Jigsaw and deployed minified to GitHub Pages.

06 — Reflection

Coding my own design taught me how layout decisions affect build effort. Next I'd add accessibility testing and a lighter image strategy.
