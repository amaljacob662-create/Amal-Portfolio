Project info

This project explores how digital products can be designed so that everyone can use them — including people with visual, motor and cognitive impairments.

Research, personas and ideas informed concrete design improvements to an order form, with a focus on contrast, labels and clear instructions.

My role

Tools

View the FigJam board ↗

01 — Overview

An audit and redesign of an order form, so people with visual, motor and cognitive impairments can complete it.

02 — The problem

The form excluded users without meaning to: low contrast, tiny text, missing labels and controls that were hard to use without a mouse.

03 — Research and insights

This is an accessibility audit and redesign concept, not certification of full WCAG compliance. The implemented form would need keyboard and assistive-technology testing.

  • Personas for low vision, motor and cognitive needs
  • Audit informed by WCAG 2.1 AA: text contrast, readable type, labels, keyboard focus and clear language
  • Biggest barriers: pale labels and no instructions next to fields

04 — Design process

  1. Research→
  2. Personas→
  3. Audit→
  4. Ideas→
  5. Redesign

Barriers were mapped per persona on the FigJam board and prioritised by impact.

05 — Final solution

Stronger header contrast, bold readable labels with required markers, hints under each field, grouped dates and a full-width button.

06 — Reflection

Accessibility is not an extra layer — designing for edge cases made the form calmer and clearer for everyone. Next I'd test it with a screen reader user.
